# 🏠 House Price Analysis using NumPy

## 📌 Assignment Overview
This project demonstrates how to generate and analyze *10,000 random house prices* using *NumPy, handle **outliers*, and visualize the data distribution.

The work is completed as part of an internship/learning assignment using *Python, NumPy, Pandas, and Matplotlib*.

---

## 🎯 Objectives
The main goals of this assignment are:

1. Generate 10,000 random house prices using NumPy
2. Calculate the average (mean) house price
3. Detect and remove outliers using the *IQR (Interquartile Range) method*
4. Visualize the price distribution using:
   - Histogram
   - Box plot
5. Understand the difference between *Pandas Series and DataFrame*
